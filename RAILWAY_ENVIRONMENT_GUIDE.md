# 🐘 Railway PostgreSQL Environment Variables Guide

## 📋 Variable Explanations

### ✅ VARIABLES YANG DI-GENERATE OTOMATIS (TIDAK PERLU DIISI)

```bash
# ⚠️ JANGAN DIUBAH - Railway generate otomatis
DATABASE_URL=postgresql://username:password@host.railway.app:7432/database_name
DATABASE_PUBLIC_URL=postgresql://username:password@host.railway.app:7432/database_name
PGDATA=/var/lib/postgresql/data
PGHOST=containers-us-west-1.railway.app
PGPORT=5432
PGUSER=postgres
PGDATABASE=postgres
POSTGRES_DB=postgres
POSTGRES_USER=postgres
SSL_CERT_DAYS=365
RAILWAY_DEPLOYMENT_DRAINING_SECONDS=30
```

### 🔐 VARIABLES YANG PERLU ANDA SET (HANYA INI)

```bash
# ⭐ SATU-SATUNYA YANG PERLU ANDA SET MANUAL
POSTGRES_PASSWORD=your-secure-password-here

# ⭐ UNTUK SECURITY BACKEND
SECRET_KEY=your-jwt-secret-key-here

# ⭐ UNTUK CORS (PENTING!)
CORS_ORIGINS=https://your-frontend.vercel.app,http://localhost:5173

# ⭐ UNTUK ENVIRONMENT
ENVIRONMENT=production
```

## 🛠️ STEP BY STEP SETUP

### Step 1: Di Railway Dashboard

1. **Add PostgreSQL Service**
   ```
   Railway → New Project → + New → Database → PostgreSQL
   ```

2. **Set Password Database**
   - Railway akan menampilkan popup untuk set password
   - Masukkan password secure: `fresh-postgres-2024-secure`
   - Railway akan otomatis generate semua `PG*` variables


## 🚨 COMMON MISTAKES

### ❌ JANGAN LAKUKAN INI:

1. **Jangan isi DATABASE_URL manual**
   - Railway auto-generate ini
   - Isi manual bisa break connection

2. **Jangan ubah PGHOST, PGPORT, dll**
   - Railway manage ini otomatis
   - Ubah manual bisa cause connection error

3. **Jangan lupa CORS_ORIGINS**
   - Frontend tidak bisa akses API tanpa ini
   - Harus include Vercel domain

4. **Jangan gunakan password lemah**
   - POSTGRES_PASSWORD harus secure
   - SECRET_KEY harus unique dan secure

### ✅ YANG HARUS DILAKUKAN:

1. **Set POSTGRES_PASSWORD** (saat add PostgreSQL)
2. **Set SECRET_KEY** (generate baru)
3. **Set CORS_ORIGINS** (domain Vercel)
4. **Set ENVIRONMENT=production**
